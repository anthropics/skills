# Instagram Analytics Tracking Template

Daily monitoring spreadsheet for the 15-day Instagram monetization sprint. Track views, engagement, followers, and sponsorship progress.

---

## Daily Tracking Sheet Format

Use this template in Google Sheets, Excel, or CSV. Track these metrics for each day:

### Column Headers

| Date | Day # | Reel Title | Video URL | Views | Likes | Comments | Saves | Shares | Followers | New Followers | Engagement % | Video Completions | Revenue This Day | Sponsorship Inquiries | Notes |
|------|-------|-----------|-----------|-------|-------|----------|-------|--------|-----------|---------------|--------------|-------------------|------------------|-----------------------|-------|

### How to Fill Each Column

**Date**
- Format: MM/DD/YYYY or YYYY-MM-DD
- Example: 08/07/2026

**Day #**
- Sequential day in 15-day sprint
- Example: 1, 2, 3, ... 15

**Reel Title**
- Name from your content calendar
- Example: "Husband Wife Reality Check"

**Video URL**
- Link to the posted Reel
- Example: instagram.com/reel/ABC123/

**Views** (from Instagram Insights)
- Total video views for this Reel
- Source: Instagram Insights > Posts > Video Views

**Likes**
- Total likes received
- Source: Manually count or from API

**Comments**
- Total comment count
- Note: Track positive vs critical separately if needed

**Saves**
- How many times saved (key engagement metric)
- Often correlated with monetization

**Shares**
- Shares to Stories/Messages
- Best engagement signal

**Followers**
- Total follower count at end of day
- Example: Start day at 5,234, end at 5,287

**New Followers**
- Followers gained this day only
- Formula: Today's total - Yesterday's total

**Engagement %**
- ((Likes + Comments + Saves + Shares) / Impressions) × 100
- Industry standard: 1-3% = good, 3-5% = great, 5%+ = exceptional

**Video Completions %**
- % of viewers who watched full video
- Source: Instagram Insights > Video Completion Rate
- Target: 70%+ for short Reels

**Revenue This Day**
- Estimated earnings from Reels Program
- Formula: (Views × $0.04-0.08 per 1K views) = rough estimate
- Update after payment from Instagram

**Sponsorship Inquiries**
- Count of brand DMs/emails received
- Helps track sponsorship momentum

**Notes**
- Any observations, issues, or changes
- Example: "Video got shadowbanned", "Trending audio", "Posted at 9 AM IST"

## Engagement Quality Tracking

Beyond quantity, track engagement quality:

| Metric | Target | Notes |
|--------|--------|-------|
| Comment Quality | 70%+ positive | Are comments positive/interested? |
| Follower Quality | Relevant audience | Do new followers match niche? |
| Share Rate | 3-5% of reach | Shares = high interest |
| Save Rate | 5-10% of reach | Indicates educational/useful content |
| Click-Through | Track via Linktree/bio link | How many click your link? |

### Negative Engagement Watch

Track and respond to:
- Negative/critical comments (respond professionally or delete spam)
- Follower drops (indicates unsatisfied audience)
- Sudden view decrease (possible shadowban or algorithm change)
- Spam comments (delete and report)

## Google Sheets Template (Copy-Paste Ready)

Use this structure in Google Sheets:

```
A1: Date
B1: Day
C1: Reel Title
D1: Views
E1: Likes
F1: Comments
G1: Saves
H1: Engagement %
I1: Followers
J1: New Followers
K1: Revenue
L1: Sponsorship Inquiries
M1: Notes

A2: 08/07/2026
B2: 1
C2: Husband Wife Reality
D2: 2340
E2: 178
F2: 43
G2: 89
H2: =((E2+F2+G2)/D2)*100
I2: 5234
J2: 45
K2: 187
L2: 0
M2: Posted 9 AM IST

[Continue for rows 3-16 (15 days)]
```

### Formulas to Add

**In Column H (Engagement %):**
```
=IFERROR((E2+F2+G2)/D2*100,0)
```

**Total Views (Sum all days):**
```
=SUM(D2:D16)
```

**Average Engagement Rate:**
```
=AVERAGE(H2:H16)
```

**Total New Followers:**
```
=SUM(J2:J16)
```

**Projected Revenue:**
```
=SUM(D2:D16)*0.06/1000
[Assumes $0.06 per 1K views average]
```

## Warning Indicators (Act Quickly)

| Indicator | What It Means | Action |
|-----------|--------------|--------|
| Views suddenly drop 50%+ | Possible shadowban | Check comments for spam, audit hashtags |
| Engagement rate below 8% | Content not resonating | Switch content style or posting time |
| No new followers for 24h | Algorithm not recommending | Post more frequently, use trending audio |
| Negative comments spike | Content controversial | Review comments, consider response strategy |
| Sponsorship inquiries 0 after day 10 | Not attractive to brands yet | Increase posting frequency, add CTAs |
