# Debugging Playbook

## Protocol

1. Capture the exact error.
2. Identify the failing component.
3. Classify the failure.
4. Find the smallest root cause.
5. Apply the smallest robust fix.
6. Explain why it works.
7. Verify.

## Common categories

- imports/dependencies
- syntax
- data and schema
- tensor/array shapes
- configuration
- API/model availability
- logic
- environment
- deployment
