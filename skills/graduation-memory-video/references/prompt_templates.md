## Person Description Guide

### Script A (single person)
Extract from user's photo: gender, age, hair style/color, skin tone, facial features (extremely detailed), build, demeanor. Copy-paste identical text across all 6 prompts.

Example: `a young Chinese woman in her late 20s, with long black hair flowing past shoulders, warm brown eyes, gentle smile, fair skin with warm undertones, slender graceful build, warm intellectual demeanor`

### Script B (two persons)
- `[HEARTTHROB_DESC]`: If user provides reference → extract features. If conceptual → build detailed description like: `a young handsome Asian man around 22-25, short neat black hair, warm bright eyes with sparkle, defined jawline, fair skin, athletic lean build, expression shifting between bashful shyness and sunny confidence, charming campus heartthrob demeanor`
- `[USER_DESC]`: Extract from user's photo same as Script A.
- Both descriptions must be clearly DISTINCT (different hair, different features) to avoid AI confusing them as same person.
