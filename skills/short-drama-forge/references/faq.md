# FAQ/故障速查（症状→第一步恢复）

> 改稿回炉前先查这张表；表治不了的再回 SKILL.md 对应 Gate 重走。

| 症状 | 第一步恢复 |
|------|-----------|
| progress.md缺失或与文件不符 | 以文件夹已有文件为准重建阶段，列出来跟用户确认 |
| 钩子3版全被否 | 回骨架检查：多是一句话核心的冲突/代价不清，先修B块 |
| 中途想换方向 | 回阶段1；旧稿移入drafts/_废弃/（不删），重出骨架 |
| 分镜超时长或密度不达标 | 按秒级模板砍时长；密度不够先加插入特写与视觉风格层，不加废戏 |
| AI转折又是套路 | 不修，切「5个方向」模式让用户选了自己写 |
| 角色视觉描述词对不上 | 以项目卡D块固定词为唯一权威，分镜与资产清单逐字替换 |
| 素材原著太短撑不起60秒 | 只叠「一个异常→追查→更荒诞真相」，不加新角色；用烟火细节加厚，不加无关支线 |
| 成品感觉平庸单一 | 对照预算表15行逐项查：先点密度与引擎，再逐镜增量/冲突对/爽阀/多线/互动/逻辑链/媒体/母题，最后密度/语系/声部/美术 |
| 剪出来读不出在表达什么／镜头还是跳 | 逐镜查承接句五型哪型断→场景切换查转场三件套→切点查首尾帧对照→全表连词测试；无对白镜查三锚点（旁白给义/视觉回声/声音桥），缺哪补哪，不整段重写 |
| storyboard-check.js 报FAIL | FAIL级照单回炉（缺承接句补/台词超20字砍/切点行数补齐/超8秒拆镜）；警级人工拍板（承接句五型关键词未点名/微切偏差） |
| 爽文向爽感不够 | 查打脸三件套是否缺嚣张镜/围观镜；憋屈段够不够20秒；反派是不是输太容易（补「凭什么轻敌」一镜） |
| 剧情还是觉得普通low | 查三味药：视角是否平铺（换七型）→代价是否具体（挂数字/物件）→冲突是否通用款（绑双层身份重写） |
| 剧情跑偏（写出来的和想写的不符） | 题材以项目卡C块为唯一源；跑偏先回Gate 0重立C块，已写稿移入drafts/_废弃/（不删） |
| 选题被毙（老掉牙/太日常/烂大街） | 查「选题门禁」三关：「没见过的点」写不出来就换选题；日常题给题眼加「奇」（异常/反常视角/离谱设定）；标配桥段写出差异化点再用，写不出就弃 |
| 想加打架/追打/辱骂戏增强冲突 | 查「内容红线」：动手与侮辱一律换掉——语言交锋/证据反转/规则压制/实力揭晓同样有张力，结局落点必须暖 |
| 对话被话题拦截红条 | 新建对话；说「继续《xx》」让skill读progress.md接续；用合规词汇（虚构寓言/剪影留白/画外），不堆敏感词；干净措辞仍拦＝误报走右上角反馈 |
| 反推文档生成后LibTV复刻不像 | 走复刻验证闭环：回传结果过5维度对比（脸/比例/风格区域/色彩/负面词），差镜回炉prompt不重建整表；人物复刻优先垫图 |
| 联系表读不出/帧缺失 | 先查imencode+tofile（中文路径imwrite静默失败）；超长截图按~1800px切块再读 |
