# AI默认毛病与去AI味（v2 · 2026-11-04 加浓度分/分层/保护区）

## AI默认毛病

平均用力：一次性写全长，开头不抓人、中间流水账、结尾没余味。
正确但无聊：结构完整、台词通顺、情绪到位，但没有戳中人的那一下。
标准人：角色没怪癖，说话像模板，遮名字认不出谁说的。
爱解释：旁白解释背景、形容词直陈情绪。
爱写长：润色默认砍30%。

## 分工表（导演 vs 助理）

| 模块 | 谁 | 原因 |
|------|----|------|
| 一句话核心 | 你 | AI没有「你想表达什么」 |
| 角色性格/说话方式 | 你定，AI执行 | 不给怪癖AI就写标准人 |
| 钩子 | AI按模式库写3版带评分，你选 | 开头决定完播率 |
| 转折+高潮 | 你写 | 全片最值钱的地方，AI只会套路 |
| 尾巴/悬念 | 你选 | AI写3版你挑余味 |
| 旁白/台词润色 | AI分层改，你砍 | 砍到少一个字都不行 |

## 浓度分（先算分，再动手，改完再算一次）

算法：命中处数 ÷ 剧本总字数 × 1000 ＝ 浓度分（处/千字）。旁白重的本子把旁白单独算一遍。

| 类别 | 词表（命中即计1处） | 目标 |
|------|------|------|
| A 填充词 | 不禁、忍不住、下意识地、不由得、情不自禁、微微一笑、轻轻叹了口气、嘴角微微上扬、眼中闪过一丝、顿时、瞬间、恍然大悟、深吸一口气、心中涌起 | 0 |
| B 情绪命名 | 愤怒地、悲伤地、开心地、紧张地、害怕地（形容词+地直陈情绪）＋「一股暖流/寒意/怒火」 | ≤1 |
| C 比喻连接 | 仿佛…一样、犹如、宛若、如同…似的、涌上心头 | 0 |
| D 烂对话副词 | 淡淡地说、冷冷地说、缓缓地说、轻轻地说、微微一笑道 | 0 |
| E 套路转场 | 与此同时、另一边、此时此刻 | 0 |

流程：组装稿算一次（前分）→ L1+L3 改完算一次（后分）→ 交付时报**消除率＝（前分−后分）÷前分**。
合格线：总浓度分 ≤2处/千字 且 A/C/D/E 类为0。前分已达标＝跳过L1直进L2体检。
例外：角色语言指纹不算命中（角色设定就是爱说「顿时」，保留并写进D块说话方式）。

## 三层改法（只动台词·旁白，保护区禁动）

**L1 机械删（安全，照词表直接删/替换）**：A/C/D/E 类逐处删——删掉不伤句意，一律删；「淡淡地说」→「说」。
**L2 标黄定位（只标不改）**：把深层AI味逐处标黄列清单（镜号＋问题类型），等人拍板：
- 旁白解释背景（改成动作和画面带出）
- 形容词直陈情绪（「悲伤地走」类）
- 三段式排比
- 连续多镜节奏均匀同构
- 无目的台词（寒暄、复述已知信息）
- 安全比喻（「像一只温顺的小猫」）
**L3 语义精修（只接L2标黄的）**：tell→show（「悲伤地走」→「低着头踢石子」）；旁白砍30%；每句台词至少一个目的（推进情节/揭示人物/制造冲突），删光寒暄；排比改两项或四项；长短句交错。

## 保护区（去AI味一律禁动，误动＝分镜链断裂）

1. 分镜表里**除「对白·旁白」列外的一切**：画面描述、承接句「接上镜：」、〔功能：〕标注、景别/光影/音效/运镜列——这些是给LibTV的机器指令，不是文章。
2. 角色固定视觉描述词（项目卡D块逐字那套）。
3. 资产prompt全部。
4. 切点四关系+桥接清单表。
台词列可以改，但改完必须：单句≤20字重过一遍＋跑 scripts/storyboard-check.js。动了保护区任何一条＝回阶段4重新过镜头因果链。

## 情绪验证五问（任何一项不过不交付）

开场30秒有「太过分了」反应？中间≥2次「然后呢」？结尾「所以后来呢」？不现实处为0？反派又恨又怕（或又笑又心酸）？

## 自测三问

前5秒能不能让随便刷到的人停下来？中间节奏塌不塌？结尾想不想转发／想不想追？

## 对标样本法

别只说「写得好一点」。给AI一个具体参照物＋节奏描述＋「不要写成~，要写成~」。
例：参考《中国奇谭·小妖怪的夏天》的叙事节奏：前30秒建立日常→突然一个异常→追查→发现一个比想象更荒诞的真相→结尾留一个让人心酸的细节。不要写成爽文，要写成「笑着笑着想骂人」。
