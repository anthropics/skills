# 短剧系列 · 爆款与合规执行规则 v1

> **用途**：本文件作为短剧全系列（任意题材）内容创作、分镜、成片、发布各环节的可执行规则。执行时逐条对照、逐项打勾；与旧稿冲突时以本文件为准。

---

## 〇、合规前提（规则依据 · 务必牢记）

1. **平台治理**：短视频平台对"动漫人物形象演绎血腥、暴力、恐怖"有专项治理，动画/影戏演绎暴力恰在打击范围内。
2. **平台公约**：主流短视频社区公约明令禁止"虐待动物""血腥暴力惊悚引人不适"。

## 一、爆款规则

### A 平台喜欢推（完播与推荐）
- **R-A1** 单集 ≤150 秒，最佳区间 60-120 秒；内容确实需要超长时，拆上下集，不硬撑单条。
- **R-A2** 前 3 秒必须出现最强冲突/最奇瞬间，禁止慢铺垫开场；钩子镜不得超过 4 秒无冲突。
- **R-A3** 情绪曲线 ≥3 段（憋屈→坠→爆→余味）；每 25 秒内给到一次情绪价值，防中途划走。
- **R-A4** 系列续集连更，片尾"未完待续"保持账号追更权重。
- **R-A5** 情绪标签走高互动情绪（心酸/想骂人/爽/暖，按题材选配），不做血腥猎奇、不做纯爽。

### B 用户喜欢看（共情与留存）
- **R-B1** 每集至少 3 个共情细节锚点（写法：角色在绝境里仍保有的小动作/小坚持，不靠台词喊出来）。
- **R-B2** 核心反差必须双层（示例：护崽的是"妖"、行凶的是"人"；结尾人化回妖）。
- **R-B3** 憋屈段不超过全片 1/3，中段必须有"小扬"暖点。
- **R-B4** 结尾留反转＋余味（金句＋悬念钩子），诱导二刷与评论。

### C 好爆（传播与二创）
- **R-C1** 每集 1 个视觉记忆点（现形/剪影等标志性画面），便于二创、截图、封面。
- **R-C2** 每集 1 句可截图金句。
- **R-C3** 话题引导到"母爱/群氓/人性"等公共命题，不做事件猎奇。
- **R-C4** 置顶评论设计 1 条能引发站队的提问。

## 二、合规·不侵权规则

### D 红线（不可触碰）
- **R-D1** 不出现现实事件对应表述：不打"改编自真实事件"等旗号、不用真实事件地名与关键词；片头、简介统一"虚构寓言"定位。
- **R-D2** 不直呈暴力执行：不拍击打落于身、不拍火燎于身/焦身；写实镜零血腥。
- **R-D3** 伤害执行主体 ≠ 未成年人：未成年角色只指证/喊话/围观，不接触、不执行伤害。
- **R-D4** 不出现未成年人食人/食生肉暗示。
- **R-D5** 不用真地名、不搬他人视频画面/文案/标题。

### E 风险分级处理
- **E1 暴力去写实化**：暴力以背光剪影＋墙影留白＋声音承载（示例：举棍剪影一声闷响即切墙）。
- **E2 未成年角色"妖种"化**：开篇给兽形早伏笔，明确"这是寓言不是现实小孩"。
- **E3 血腥恐怖尺度**：影戏/剪影为唯一暴力载体；封面、标题禁用暴力关键词。
- **E4 迷信边界**：神怪/志怪题材统一定位"虚构寓言·批判指向人心"——验的是人心，不是妖；避免被误读为宣扬怪力乱神。
- **E5 版权素材**：事实与结构可借（三件套：借结构、原创表达、虚拟地名），画面/文案/标题必须原创；字体、音源须有商用授权；AI 生成素材按平台条款留痕。
- **E6 舆情反噬**：发布口径走"母爱/寓言/反转"，不蹭真实事件热度；置顶评论引导"聊聊人性，拒绝消费苦难"。

### F 发布口径（每集必做）
- **F1** 定位语：虚构寓言（神怪向可写"志怪寓言"）。
- **F2** 声明（画面或简介必加）："本片为虚构故事，不指向任何真实人物与事件。"
- **F3** 话题词黑名单：与题材相近的真实事件地名/事件关键词、暴力关键词、悲剧消费词。
- **F4** 话题词白名单：#虚构寓言 #人性 #反转（按自己作品题材替换为自有话题词，如 #志怪寓言 #国风动画 #治愈）。
- **F5** 遇平台审核提示：按平台指引删改对应镜头，不争论、不申诉对抗、不换号规避。
- **F6** 成片内备注（剪辑必加）：片头黑屏字卡后加 2 秒「本片为虚构故事，人物与情节不指向任何真实事件。」；片尾"未完待续"前加 3 秒「本片为虚构故事，不指向任何真实人物与事件。」；全程画面角落小字「故事虚构」，字号 ≤ 正文字号 1/2、透明度 ≤40%、不遮关键画面。
- **F7** 备注禁用表述：不写"改编自真实事件 / 真实事件改编"（会反向挂钩）；备注不能替代删改——若画面仍直呈暴力，备注无效，审核以画面为准。

## 三、执行检查表（每集发布前逐条打勾）

- [ ] 时长 ≤150 秒；前 3 秒有冲突/最奇瞬间
- [ ] 情绪曲线 ≥3 段；每 25 秒一次情绪价值
- [ ] ≥3 个共情锚点；核心反差双层
- [ ] 1 个视觉记忆点 ＋ 1 句金句
- [ ] 无直呈暴力/血腥写实镜头（暴力只走剪影＋墙影＋声音）
- [ ] 未成年角色不执行伤害（只指证/围观）
- [ ] 无"改编自真实事件"及真实事件关键词表述
- [ ] 定位语"虚构寓言"＋发布声明已加
- [ ] 话题词只走白名单
- [ ] 置顶评论已设
- [ ] 字体/音源/AI 素材授权已核
- [ ] 片头/简介为"虚构寓言"定位，无真地名

## 四、红线速查（30秒版）

1. **不碰真事**：无真地名、无"改编真实事件"、无暴力关键词
2. **不留血**：无击打落于身、无火燎于身、写实零血腥
3. **不打孩子**：未成年只动嘴不执行，无食人暗示
4. **不蹭热度**：话题走母爱/寓言/人性
5. **必带声明**：虚构寓言定位 ＋ 发布声明
