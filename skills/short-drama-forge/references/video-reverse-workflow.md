# 视频反推工作流（路径V）

> 用途：给一条成片，反推成「可直接粘贴进LibTV复用」的md拆解文档。吸收自 reverse-prompt 技能思路＋实战复盘。

## 触发

用户丢视频文件＋说「拆解/反推/逆向」→走本路径，不走项目卡流程。产出为独立md，可另存为标杆案例（references/case-*.md）。

## 工作流五步

1. **探测**：ffprobe（时长/画幅/fps/音轨）；本机ffmpeg/ffprobe在scoop，无whisper——对白靠烧录字幕读。
2. **双阈值切点**：ffmpeg select scene 0.3＝节拍层、0.06＝微切层，两个数都记（实测两片 83/365、56/235，≈4.4微切/节拍是通用结构）。
3. **联系表**：python PIL/cv2切块——每节拍取中点帧、S编号＋时间戳上标、2列×3行拼sheet；中文路径imwrite会静默失败，必须imencode+tofile；超长截图先查im.size再按~1800-2000px高crop切块。
4. **逐镜读**：sheet逐张读，字幕（对白）、画面、景别全读出；对白多的片子优先读字幕层。
5. **出文档**（固定结构，见下）。

## 拆解文档固定结构

```
# 《片名》第X集 拆解反推 · LibTV出片文档
> 源视频信息｜节拍数/微切数｜口径说明（✅=硬事实：时长/画面/景别/字幕逐帧读出；⚠️=推断：运镜/音效/复现prompt按画面反推）
一、一句话反推
二、总参数（画幅/风格词锁定/字幕样式/配音音效方向/叙事结构）
三、角色卡（固定视觉描述词＋识别锚点＋多状态资产）
四、场景表／道具表
五、视觉语言清单（独立风格资产：影戏/VFX/剧中媒体）
六、节奏反推（秒级＋五模块映射＋情绪拐点密度）
七、分镜表（九列双层：节拍行＋角度组＋微切预算）
八、复现坑位（漂移点/画幅重构/长镜拆分/金句禁改）
```

## 置信度双标记（吸收自reverse-prompt）

- ✅硬事实：逐帧读出的（时长/画面/景别/字幕/切点数）——可依赖。
- ⚠️推断：按画面反推的（运镜/音效/prompt/情绪意图）——文档里显式标注，不得混入✅区冒充事实。
- 生成词 vs 后处理词必须分列：生成词＝LibTV可直接生成的画面内容；后处理词＝需剪辑实现（叠字/时间戳/变速/拼接/配音/BGM/扫描线滤镜）。剧中媒体寄存器（监控时间戳/新闻滚动条/红章）多为AI静帧＋后处理叠字——便宜且加真实感。

## 资产prompt硬性原则（写角色图/三视图prompt前必核，吸收自reverse-prompt）

1. 风格词范围限定：多风格堆叠互相稀释；写明作用区（「厚涂只用于头发」「水彩晕染只用于背景」）。
2. 人脸细节保护必填：「五官轮廓清晰、皮肤细腻、眼睛有明显高光点、虹膜颜色清晰、头身比例正常、五官比例协调」；人脸不与水彩混用。
3. 眼神锚定：禁「望向远方/眺望」模糊词；改「凝视画面右上方某点＋情绪＋眼形（眼尾上扬/双眸低垂）」。
4. 角度与年龄感：禁「可爱/萌/少女」（幼化比例）；锁「略微仰视、侧脸轮廓清晰、下颌线分明」。
5. 人物类负面词模板：文字，水印，签名，畸形脸部，错误五官比例，头大身小，脸崩，眼睛大小不一，嘴歪，多手指，低质量。
6. 参考图（垫图）：人物复刻仅文字上限≈60%，配参考图→85%+；分镜复现优先用角色基准图垫图，而非纯文字。
7. 原创性声明（用户红线）：参考画风只译成通用美术术语（手绘二维/水彩/宣纸纹理/墨线勾边）；prompt声明「原创设计，不参考任何已有动画IP」；角色形象与参考作品零对应。

## 复刻验证闭环

反推交付≠结束。用户在LibTV生成后回传，每次迭代必走5项：主体相似度（脸/神态/发型/服装）／比例（头身/五官）／风格实现度（是否作用在指定区域）／色彩光影还原／负面词生效（无文字水印）。差异大的镜回炉prompt，不重建整表。

## 反AI腔

拆解文档不写「让我从几个角度分析」；直接开干、格式固定、prompt可直接复制粘贴。
