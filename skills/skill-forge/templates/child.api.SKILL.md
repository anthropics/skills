# {{链接名}}（接口版）

**一句话**：直接调 `{{host}}` 的一个接口取数，不点页面、不怕改版。

## 怎么跑

```bash
node scripts/api_run.mjs --config 配置                       # 预览前 5 行
node scripts/api_run.mjs --config 配置 --param date=2026-11-03 --out 结果.csv --go
```

- `--param k=v`：覆盖配置里的参数（日期、账户、页码等），可传多个
- 默认只预览；`--go` + `--out` 才落 CSV
- 本链路是 {{method}} 接口：**若是写接口（POST/PUT/PATCH/DELETE），必须 `--dry` 核对无误后再加 `--allow-write --ack "上限=…｜批准=…"` 两样齐全才真跑**，确认原文会写进 `logs/写操作确认.log` 留痕
- 退出码：0 通过 / 2 校验不过 / 3 请求失败（多半是登录态失效）/ 4 配置问题或没加 --allow-write / 5 --ack 没写清上限和批准人

## 硬规矩

1. **登录态**：走 {{port}} 端口那个浏览器（独立 profile）。掉登录就在窗口里登一次，脚本不用改。
2. **校验不过就报错**：行数不够、必需字段缺失直接非 0 退出，不会给你一张空表。
3. **只读**：这条链路是 GET/只读接口。要改成写操作，先问人。
4. 页面改版/接口改字段时：先看 `--param` 换一组参数是否正常；仍不对就回工厂重录（`skill-forge`）。

## 收尾

- **终点**：CSV 落盘 + 校验通过 = 做完，浏览器**立刻关**（接口版走页面内 fetch，也要关）
- **关谁**：按 `--remote-debugging-port={{port}}` 只关本链路自己开的那台 Chrome（认端口不认进程名；禁止按进程名杀）
- **逃生**：`--keep-open`，默认关
- **日志**：`关闭浏览器 port=... remaining=0`
