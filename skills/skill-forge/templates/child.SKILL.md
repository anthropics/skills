## 怎么跑

```
cd 本包目录
# 1) 先预览（不动浏览器、不贴）：
node scripts/run.mjs --config 配置 --source <本次导出的文件>
# 2) 确认预览无误，真跑（会开浏览器、回放、粘贴、复核）：
node scripts/run.mjs --config 配置 --source <本次导出的文件> --go
```

命令速查（Windows 拖拽跑法在内）见 `一键跑.md`。

## 铁律

1. **先预览后真跑**：不带 `--go` 永远只预览。
2. **唯一键重复整轮停**：源表本身不对时绝不硬贴。
3. **回读少一行都算失败**：报"完成"前必须看到"复核通过"。
4. 页面元素找不到 → 大概率改版：回工厂 `manage.mjs fail --link {{链接名}} --phenomenon "..."`，失败 3 次整条重录，别手工绕。

## 收尾

- **终点**：贴完 + 回读复核通过 = 做完，浏览器**立刻关**，不用留着复核
- **关谁**：按 `--remote-debugging-port={{port}}` 只关本链路自己开的那台 Chrome（认端口不认进程名；禁止 `Stop-Process -Name chrome`）
- **逃生**：`--keep-open` / `KEEP_BROWSER=1`，默认关
- **日志**：`关闭浏览器 port=... remaining=0`

> 不关的后果不是报错，是机器越来越卡、下次任务抢不到实例。

## 依赖

Node 24+（自带 WebSocket），Chrome。登录态在工厂的 chrome_profile 里（首次要人登一次）。
