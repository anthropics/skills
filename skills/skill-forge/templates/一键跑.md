# 一键跑（命令速查）

## 预览（不动浏览器、不贴数据）

```
node scripts/run.mjs --config 配置 --source <本次导出的文件>
```

## 真跑（会开浏览器、回放、粘贴、回读复核）

```
node scripts/run.mjs --config 配置 --source <本次导出的文件> --go
```

## Windows 想拖拽跑

把导出文件拖到 `一键跑.cmd`（自己建一个，两行即可）：

```
@echo off
node scripts\run.mjs --config 配置 --source "%~1"
```

> 技能市场/公开渠道的包不带 .cmd（平台不收可执行脚本）；本地自用随时可以按上面两行建一个。
