## 二、在用功能（13 项，各一个入口）

| 功能 | 脚本 / 入口 | 说明 |
|---|---|---|
| ① 录制 | `scripts/record.mjs` + `assets/recorder.js` 浮标 | CDP 驱动真实 Chrome；记点击 6 级定位、跳转、XHR/Fetch 的 URL/入参/状态/耗时/响应字段/行数；同 tab 跳转重注入，新 tab 只跟 http(s)；**录完若发现同名上一份 rec，自动跑 diffrec** |
| ② 证据 + 探查 | `scripts/evidence.mjs`、`scripts/probe.mjs` | 证据包（时间线 + 接口候选打分）；探查复现该请求、判定「能接口化」，出 `接口配置草稿.json` |
| ③ 判参 | `scripts/diffrec.mjs` | 两份 rec 逐层 diff → 常量/变量/body 模板/只出现一次的请求；产出 `对比报告.md` + `参数判定.json` |
| ④ 问需求 | `scripts/interview.mjs` | 交互或 `--answers`；11 个问题覆盖触发/参数/产出形态/判据/失败/写操作；**答不上来记「待确认」不拦生成**，`--strict` 才硬拦；产出 `配置/触发.json`，`build_skill` 自动把「## 什么时候跑」写进子技能 | 2026-11-06 |
| ⑤ 生成 | `scripts/build_skill.mjs` | `--type api|ui`；接口版强制原文模板 + 字段数；产物 `produced/<链路>/` + `zip/` + 台账一行 |
| ⑥ 执行 | `scripts/api_run.mjs`（接口版）、`scripts/run.mjs`（UI 版） | 接口版：页面内 fetch + 模板渲染 + 四重校验，`--dry` 只渲染；UI 版：回放定位库 + 合成粘贴 + 回读 |
| ⑦ 独立登录 | `scripts/login.mjs` | 专属 user-data-dir 账密登录；成功必须有证据（URL 到达/成功元素出现），失败 exit 2 |
| 失败归因 | `scripts/diagnose.mjs`、`scripts/lib-diagnose.mjs` | 9 条规则（CAPTCHA/LOGIN/RATE/SEL/FIELDS/EMPTY/TIMEOUT/SERVER/FS）；`manage.mjs fail` 记账时自动调用 |
| 单遍判参 | `scripts/infer_params.mjs` + `scripts/lib-infer.mjs` | 一条 rec 出变量提示（日期/接口带出/URL 带出/长单号/金额），输出 `参数判定.csv`；固定提示「不是定论」 | 
| 失败自愈 | `scripts/lib-heal.mjs`（`run.mjs --heal`）、`manage.mjs heal` | 逐级降级重试 + 可选回写定位库 + 自愈记录查询 | 
| 子包说明书 | `scripts/lib-manual.mjs`（`build_skill` 调用） | 生成 `说明书.md`，人看/模型读都行 | 
| 浏览器外 | `scripts/localview.py` | 读下载下来的 xlsx/csv/tsv/json（行数/列名/样例行，零第三方依赖）；`--open` 调系统程序打开给人看；`--dir --latest 3` 找刚下载的那份 |
| 出包验收 | `scripts/pack_check.py` | 出包 + 六项验收一条命令；平台上传只发它出的包（详见 `references/打包与验收.md`） |
| 农场互通 | `scripts/lib-farm.mjs`（build_skill 调用）+ `lib-cdp.mjs` 的 farmSlotOf/closeChromeSmart/farmPreWriteSnapshot | 定位库→农场挂机脚本翻译 + 档位识别收尾豁免 + 写前快照 |

## 三、退出码口径（全部脚本一致）

| 码 | 含义 |
|---|---|
| 0 | 通过 |
| 2 | 校验不过 / 登录没成功 |
| 3 | 浏览器、页面或请求失败（多半登录态失效） |
| 4 | 配置或参数有问题（缺变量、模板缺失、路径不对、写接口没给 `--allow-write`） |
| 5 | 写接口给了开关但二次确认不合格（`--ack` 缺「上限/批准」或太短） |

## 四、怎么算验过

- 改代码 → 必须真跑：`node test/run_node_test.mjs`（9）+ `node test/run_forge_v2_test.mjs`（104）+ `node test/run_hud_test.mjs`（24）+ `node test/run_multitab_test.mjs`（13）+ `python -I test/run_offline_test.py`（7），全过才算；交付前再跑 `python scripts/pack_check.py` 一条龙；
- 加新功能 → 必须在 `test/run_forge_v2_test.mjs` 补断言，否则等于没验；
- 改链路 → 要确认真实站点跑通，并把结论写进 `references/site/<host>.md`。
