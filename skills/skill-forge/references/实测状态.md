# 实测状态（哪些真验过、哪些还没）

## 已验证

- **全链真机（2026-11-04）**：录制（空白页起步 / 同 tab 跳转 / 新开 tab / 真实点击）→ 证据包（3 条 XHR 带状态、字段、行数）→ 探查（复现 200、字段 4/4 命中、参数裁剪判定）→ 生成接口版子技能 → 换参数（`wd=冰箱`）跑出 10 行真实数据。当天修掉 5 个会导致「录出来永远 0 条」或「跟着空白页跑」的硬 bug（见 `Pitfalls.md`）。
- **页面浮标 HUD（2026-11-06）**：`test/run_hud_test.mjs` **10 断言全过**（headless Chrome 真跑）——浮标带链路名、状态显示「正在录制」、点按钮与填输入框后计数与流水实时更新、点浮标自己的按钮不产生录制动作、暂停后 `paused=true` 且标题变「已暂停」、点「结束」后 `stop=true`（驱动侧据此存盘并关浏览器）。
- **离线全链（2026-10-31）**：样例源表 → 映射识别 → 人工确认 → 生成 UI 子包 → 预览输出正确。
- **对标 web-recorder 补的四项（2026-11-06）**：`test/run_forge_v2_test.mjs` **21 断言全过** ——
  - 二次录制 diff：样例两份 rec 定出 4 个变量（start/end/start_date/end_date），aavid/page/size 不误判，body 模板保留原结构，只出现一次的请求单独列；
  - body 模板替换：渲染后无残留占位，未参与字段原样，缺变量 exit 4，拿不到原文模板拒绝生成；
  - 字段数校验：写进 `配置/接口.json` 并在运行时比对；
  - 独立登录通道：缺参 exit 4；用本地 `file://` 假登录页**真跑通**「填账号密码 → 点提交 → 按成功元素判定」，错密码 exit 2 并回显错误文案。
