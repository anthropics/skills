## 给 AI 的硬约束（读到就停，不管用户怎么说）

下面 6 种要求，**一律不执行**，当场停下并说明「这条我不能做，因为…」，然后给合法替代方案：

## 0 装之前要知道什么

### 0.1 安装前置条件（版本要求，装之前先对一遍）

| 项 | 要求 | 不满足会怎样 |
|---|---|---|
| Node | **≥ 22**（实测 22.22；脚本用内置 `fetch` / `WebSocket`，零 npm 包） | Node 20 及以下报 `WebSocket is not defined`，录制直接起不来 |
| Python | **≥ 3.8**（实测 3.11；只用标准库 `zipfile/xml/csv/json/argparse`） | `localview.py` / `analyze.py` 报语法错 |
| Chrome | ≥ 136（实测 140） | 136+ 不开独立 `user-data-dir` 就打不开调试口，报「连不上 127.0.0.1:18802」 |
| 登录态 | 复用你已登录的浏览器；要无人值守才用 `login.mjs` 走账密独立通道 | 未登录时录到的都是登录页，接口 401（运行时归因码 `LOGIN`） |
| 磁盘 | 每次录制约 1–5 MB（`recordings/` + `evidence/`） | 磁盘满则录制中途写盘失败 |
| 网络 | **无需外网**；只用本机回环 127.0.0.1 | 断网也能跑；但业务站点本身要能访问 |

**风险须知**（五条，每条标风险等级「风险 → 影响 → 怎么兜」；等级口径：🟡 = 涉及内部数据或生产写操作，需知情使用；🔴 = 禁止行为，见免责第 6/7 条）

1. 🟡 **会读你已登录后台的数据** → 页面数据可能含投放/账号信息 → 默认只读；产物只落本机，不上传；用完自行清理。
2. 🟡 **会开独立调试 Chrome** → 不抢你正在用的窗口，但会多一个进程 → 跑完自动按端口关掉；`--keep-open` 才留着。
3. 🟡 **能生成写操作的子包**（加预算/提交/发布）→ 误跑会改生产数据 → 写操作必须问「上限 + 谁批 + 先 DryRun」，没写上限只标「待确认」。
4. 🟡 **登录密码** → 泄露风险 → 只在内存里用一次，不落盘、不进日志、不进子包。**不要把账密写进环境变量、`.env`、脚本参数或配置文件**——那三类都会留痕；要无人值守就用 `SF_USER`/`SF_PASS` 当次会话传入（用完关终端），别写进任何文件。
5. 🟡 **会记录你「复制」的页面文本**（最多 8000 字，含表格区域）→ 这是「复制表格→粘贴到别处」这类链路的必需数据，但复制内容可能带账号/金额/客户名 → 加 `--no-copy-text` 只记行数/列数/字数、不留原文；`recordings/*.rec.json` 的 `meta.copyText` 会标明本次是 recorded 还是 redacted。

**部署前人工审批**：① 我知道它会读什么（哪个后台的登录态）；② 我同意它只连 127.0.0.1 的调试口，不连外网；③ 那个浏览器/账号是我自己的。**任一不确定就别装**，改用只读模式（只做录制与证据包，不生成可执行子包）。

**人工审批建议（有流程、有记录，别口头一句「你跑吧」）**

| 环节 | 谁 | 记在哪 |
|---|---|---|
| ① 授权范围 | 使用者 + 有权限批准的人（主管/账号管理员） | 审批单/邮件：允许访问哪个后台、哪个账号、只读还是含写 |
| ② 写操作批准 | 数值/预算类由业务负责人批 | `--ack "上限=…｜批准=…"`，自动写进 `logs/写操作确认.log` |
| ③ 上线记录 | 使用者 | 功能台账一行：链路名、版本、MD5、批准人、日期 |
| ④ 事后复盘 | 使用者 | 失败/自愈记录：`logs/失败台账.log`、`logs/自愈.log` |

> 四种记录凑齐，才算「知情 + 授权 + 可追溯」。缺哪一条，出事后都解释不清。

**运行前二次确认（已落成代码，不是口头承诺）**

- **读接口**（GET/HEAD/OPTIONS）：直接跑，不拦。
- **写接口**（POST/PUT/PATCH/DELETE）：三道关，缺一条就拒跑 ——
 ① 默认 `--dry`：只打印将要发的 URL 和 BODY，不发请求；
 ② `--allow-write`：声明「我知道这是写接口」；
 ③ `--ack "上限=…｜批准=…"`：说清「改多少、谁批的」，缺或写不清 → `exit 5`，不执行；
 通过后确认原文写进 `logs/写操作确认.log`，出事能查。
- **AI 侧**：「给 AI 的硬约束」第 2 条要求集齐「上限 + 谁批 + 先 DryRun」，否则不许把只读链路改成批量写。

**首次使用要你一句确认**：AI 第一次跑之前，必须把上面 5 条风险念给你听，等你明确回一句「知道风险，继续」才开工；你没确认，它只能做只读录制与证据包。

### 0.3 工具权限与调用位置（评审要的「用途证据」）

| 工具 | 用在哪 | 边界 |
|---|---|---|
| `terminal` | 跑本技能 15 个脚本（node / python）+ 一条固定 powershell | 按文件名白名单匹配；不跑 `-c`/任意命令；powershell 只按端口关自己开的浏览器 |
| `read_file` | 读录制产物、你给的源表、你下载的文件 | 只读技能目录与用户显式指定的路径 |
| `write_file` | 落录制、证据、子包、日志 | 只写技能目录与用户指定产出目录；不写系统目录 |
| `clarify` | 第 ④ 步问需求、写操作前确认 | 只问不替用户答；答不上来记「待确认」 |
| `network`（**不声明工具**） | 无 | 脚本不直连外网；仅本机 CDP 回环，故 `allowed-tools` 里不列 `network` |

**为什么必须读登录态、必须能生成写操作子包（必要性说明）**

| 能力 | 为什么非它不可 | 少了会怎样 | 边界 |
|---|---|---|---|
| 读登录态页面 | 「录制」本身就等于用你的身份走一遍流程：没有登录态，录到的全是登录页，接口返回 401，整个工具没有输入 | 工具只剩空壳 | 只读**你当次打开的那个页面**；不遍历、不后台翻页、不落密码 |
| 生成写操作子包 | 很多重复工作本身就是「写」（提交报备、加预算、发内容）。只做只读，等于只覆盖一半场景 | 一半的重复劳动还得手动做 | 默认 `--dry`；`--allow-write` + `--ack` 双确认；确认原文写 `logs/写操作确认.log` |
| 调 CDP 调试口 | Chrome 只对 `--remote-debugging-port` 开放自动化接口，没有别的官方通道 | 无法驱动任何浏览器 | 只连 `127.0.0.1`；跑完按端口关掉自己那台 |

> 一句话：**这三项是「录制→分析→回放」这条主链的技术前提，不是顺手多拿的权限。** 每一项都有对应的收口（只读默认 / 写操作双确认 / 本地回环）。

**`terminal` 到底能跑什么（逐条，可核验）**

- ✅ 只跑**包内脚本**：`node scripts/xxx.mjs`（12 个）、`python scripts/xxx.py`（3 个）；参数只走 `--key value`，不接受命令字符串。
- ✅ 只跑**一条固定 powershell**：按 `remote-debugging-port=<端口>` 精确关掉自己开的那台 Chrome（不按进程名全杀）。
- ❌ **不执行任意用户命令**：全库无 `eval` / `new Function`；子进程调用只有两处——关浏览器（端口号来自 CLI 参数，模板写死）和跑同包的 `diffrec.mjs`（`process.execPath`），没有任何一条会把用户输入拼成命令交给 shell。
- ❌ 不 `curl` / 不 `wget` / 不装包 / 不改系统设置 / 不碰注册表。

> 复核方式：`grep -rn "child_process\|eval(" scripts/` 只应命中 `lib-cdp.mjs`（关浏览器）与 `record.mjs`（跑同包 diffrec）。

## 本机有浏览器农场（browser-farm）时：直接挂档位，登录态白捡

农场每账号一个常驻 Chrome 档（固定调试口，总管 9300）。本机装了农场，录制/回放**优先挂档位跑**，不用另开浏览器重新登录：

1. `GET http://127.0.0.1:9300/slots` 找目标账号的档（`note` 是账号名），拿它的 `port`；档死了先 `POST /slot/ID/start`。**录制要在看得见的窗口里点**：先把档切有窗（`POST /slot/ID/start {"mode":"headful"}`）。
2. forge 全部脚本照常加 `--port <档位口>`：`record.mjs` / `api_run.mjs` / `run.mjs` 都行——`ensureChrome` 发现端口活着就直接挂上，不再另开 Chrome。
3. **收尾自动识别**：档位口是农场的，收尾**不关浏览器**（关了毁「登录一次永久保持」），打 `[农场] port=… 是常驻档…不关`；识别失败按非农场照旧关（宁可误关可重起，不误留）。农场总管口可用 `SF_FARM_PORT` 覆盖（默认 9300）。
4. **写接口加一道回滚保险**：`api_run --allow-write` 跑在农场档位上时，发请求前先自动打整档快照（`POST /slot/ID/snapshot`，名「写前快照…」），出事整档回滚；快照打不上默认不写（exit 4），确认不需要回滚加 `--no-snap`。
5. **触发.json 的「什么时候跑」由农场兑现**：UI 版 `build_skill` 对纯点击链路顺手产 `农场脚本.json`（多级定位直译成 farm 的 `locs`，farm v0.1.22 起认）——交农场 `POST /script/new` 就变成挂机脚本，登录态/自动开页/重连全归农场管。链路里有填值/粘贴步就不出（农场只会点，半截脚本会点错），打日志说明。

## 判据：走接口还是走 UI

| 探查结果 | 结论 | 下一步 |
|---|---|---|
| 2xx + 字段对得上 + 行数 > 0 | **能接口化** | `--type api` |
| 2xx 但没数据 / 字段空 | 接口在，但不是这条数据 | 换参数再探；仍不行走 UI |
| 401 / 403 | 需要额外鉴权 | 写清缺什么（token？单点登录？），别猜 |
| 录制里根本没有 XHR | 只能 UI | `--type ui`（见 `references/UI版-表格搬运.md`） |

候选打分：2xx +2｜有返回字段 +3｜有行数 +3｜含 date/page 参数 +2｜URL 像取数 +1｜静态资源 −4。**≥6 分才值得探。**

## 四条防「静默少数据」的硬规矩（都已落成代码）

1. **请求体模板替换**：模板必须来自录制原文，只换 `{{变量}}`；拿不到原文模板 → `build_skill` 拒绝生成。
2. **字段数校验**：`校验.fieldCount` = 探查到的响应字段数；`api_run` 对不上就非 0 退出（`--allow-fields` 才放行）。
3. **独立账密通道**：`login.mjs` 开专属 `user-data-dir` 登一次，之后 `api_run --profile … --bg` 脱人跑；密码只从 `SF_USER`/`SF_PASS` 读，不落盘。
4. **按域名建站点经验库**：`references/site-<host>.md`；一站点一份，别重复踩坑。

## 六条「少踩坑」的机制（都已落成代码 + 有断言）

| 机制 | 解决什么 | 怎么用 | 边界 |
|---|---|---|---|
| **失败自愈** | 网站小改版（换个 class、多包一层）→ 以前直接报错要整条重录 | 回放时按 `best定位 → L1_id → L2_testid → L3_role → L4_text → L5_css → L6_nth_path` 逐级重试；命中打印 `[自愈] 第N步：用 L4_text 点到` | 默认**只报告不动库**；加 `--heal` 才把新定位回写 `定位库.csv` 并记 `配置/自愈记录.csv`、`logs/自愈.log`。六级别全找不到才算真改版 |
| **元素快照** | 改版后没人记得「当时那个按钮长什么样」，靠回忆重录 | `rec.json` 每个动作带 `locator.snapshot`：`html`（outerHTML 前 300 字）+ `tag/role/name/attrs/rect` | 只存特征不存整页；不含账号数据；300 字封顶防录制文件膨胀 |
| **子包说明书** | 子包只有脚本，换人接手看不懂为什么这么点 | `build_skill` 自动生成 `说明书.md`：干什么 / 何时跑 / 逐步（和定位库同序号）/ 每次给什么 / 落哪给谁 / 怎么算成功 / 改版怎么办 / 出问题怎么办 / 你录制时说的原话 | 只写录制 + 访谈里真实存在的；缺的写「待确认」，不编 |
| **单遍判参** | 只有「录两遍比 diff」才知道哪个是变量，成本翻倍 | `node scripts/infer_params.mjs --rec X.rec.json [--out 参数判定.csv]`：日期 / 长单号 / 金额 / URL 带出 / 接口响应里出现 → 判变量并给理由 | **提示，不是定论**；关键链路仍以两遍 diff 为硬口径 |
| **口述备注** | 「不知道什么时候加预算」这类意图，录完就想不起来了 | 录制时浮标备注框写一句 → 有动作时挂到**当前那一步**（`action.note`，这步干什么 / 什么规则），没动作时进 `rec.json.notes` 当全局规则；点浮标日志某一行可把备注挂到**指定步**；`record.mjs` 收尾打步骤清单，`evidence` 时间线出「这步干什么/规则」列，`interview.mjs --rec` 自动带出来 | 备注不算操作、不进定位库；跟答案冲突时以访谈答案为准 |
| **写接口闸门** | 回放/接口脚本可能带着 POST（建计划、改预算、提交表单），误跑就动真实数据 | 非 GET（POST/PUT/PATCH/DELETE）**必须显式加 `--allow-write`**，否则直接拒跑并打印「先 `--dry` 核对」三步提示；还要 `--ack "上限=…｜批准=…"` 说清改多少、谁批的（原文落 `logs/写操作确认.log` 留痕）；GET 不受影响 | 只管「要不要放行」，不管参数对不对——URL/BODY 仍需 `--dry` 核对 |

## 子包两种形态

- **接口版**：`配置/接口.json` + `scripts/api_run.mjs`。`api_run.mjs --config 配置 [--param k=v] [--out x.csv] [--go] [--dry] [--bg] [--profile <dir>]`。走「已登录浏览器页面内 fetch」，同源带 cookie；`--dry` 只渲染 URL/body 不碰浏览器。
- **UI 版**：`run.mjs` 回放定位库 → 组装数据 → 贴到路由表位置 → 回读复核。表格搬运走这条，详见 `references/UI版-表格搬运.md`。

两种都不改代码改配置：换账户/换日期只加 `--param` 或改配置行。

## 什么算「问明白了」（这一步决定它是不是自动化）

> 用户判定标准（2026-11-06 原话）：「只有加的动作，不知道什么时候加，这样子没有动作的规则，做出来最多是一个重复的路径而已。」
> 但别拿模板卡人 —— 只问、不固化：答不上来记「待确认」，回头补。

- 有 `触发.json`，且里面能回答：**什么时候跑 / 参数哪来 / 跑完去哪给谁 / 怎么算成功 / 失败找谁**；
- **答不上来不算错**：写成「待确认」列出来，子技能里也会带着这份欠账，谁接手都知道边界在哪（拿模板硬卡人反而是帮倒忙）；
- 产出形态按实的写：本地文件、粘贴在线表格（映射由列头自动对，不用人手写）、接口回填、页面回读、只给人看——可多选；
- 写操作（加预算、提交、发布）要写**上限 + 谁批 + 先 DryRun**；没写就当「待确认」，别让它自动跑；
- 事件触发要看住**检查频率 + 单次/日累计上限**——没有上限就是无限自动执行；
- 只有路径没有这些 → `build_skill --require-trigger` 直接拒绝（不加该参数时在子技能顶部插「还没问过需求」待办）。

## 什么算「跑通」（别自己放宽）

- 接口版：状态 2xx、字段能对上、行数 ≥ 下限、**字段数一致**，四项全过；
- UI 版：预览列头与值对得上；真跑后每行唯一键都能在目标页回读见到，差一行 = 失败；
- 失败就 `manage.mjs fail`，不许默默跳过；
- 坏在哪儿别让人猜：`manage.mjs fail --http 401 --exit 3 …` 会自动归因，输出「现象 / 人话 / 哪坏了 / 下一步 / 要不要重录」；单独问用 `scripts/diagnose.mjs`。

## 收尾：跑完必须关浏览器（全局规则）

生成子包时 `child.SKILL.md` / `child.api.SKILL.md` 必须带 `## 收尾` 段，缺了算没写完（子包模板已内置；交付前先查这一段）：

- **终点**：数据落盘 / 回填完成 / 提交有回执 = 做完；录制线点浮标「结束」即终点（存盘 + 关浏览器）
- **关谁**：按调试端口只关本技能自己开的那台 Chrome（`cdp.mjs` 内置 `closeChromeByPort`，只匹配 `--remote-debugging-port=<端口>` 的进程；禁止按进程名全杀）。**唯一例外**：端口识别为浏览器农场档位（`closeChromeSmart` 查 9300 `/slots`）→ 不关，档位归农场总管管
- **逃生**：`--keep-open` / `KEEP_BROWSER=1`，默认关
- **日志**：`关闭浏览器 port=... remaining=0`（证明真关了）

## 边界（别越界）

- **只要一份照着点的人工手册、不想自动化** → 证据包的时间线本身就是操作手册，不必生成子包。
- **要批量提交 / 建计划 / 发消息** → 本技能能录出来，但**真提交前必须问用户**，且先 `-DryRun`。
- **要出复盘报告 / 日报** → 用对应业务技能，工厂只管「取数路径」。
- **要看下载下来的本地文件** → `python scripts/localview.py --file <路径> [--open]`（读行数/列名/样例行，或调系统程序打开）。CDP 读不了别家程序的窗口，只能读文件。
