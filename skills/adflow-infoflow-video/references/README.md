# AdFlow 信息流广告混剪出片 Skill

给 Claude Code 用的广告短视频生产 skill：**你说产品和素材，Claude 写文案、看素材打标签、把关合规，本地引擎自动配音、配画面、剪出成片。**

## 它能干什么

- 一条产品文案（或让 Claude 现写）→ 批量出多条竖屏广告短视频（同文案不同配音+画面组合，即"裂变素材"）
- 自动配音 + 自动字幕 + 自动按文案节奏换画面
- 内置本地广告法检查（绝对化用语、敏感词拦截），每条成片带合规标记
- 五种平台风格预设：竖屏快节奏 / 种草闺蜜感 / 直爽接地气 / 温和叙事 / 通用信息流（引擎 --platform 参数选）

## 三大特点

1. **不依赖任何大模型 API**：写文案、看图打标签这些"AI 活"由 Claude 本身完成，引擎层是纯本地确定性执行（edge-tts 配音 + 标签匹配 + ffmpeg 渲染），没有 API key 也能全流程跑通。
2. **配音可选可换**：默认微软 Edge-TTS（免费、无需注册）。想要更真人的音色？内置火山引擎、MiniMax 的注册配置教程，想换时按教程配一次 key 即可。
3. **纯小白友好**：所有操作都是一句话让 Claude 干，脚本输出全是大白话；从装 Python 开始的手把手引导文档齐备。

## 系统要求

- Windows 10/11 64 位（Mac/Linux 理论可跑但未适配）
- Python 3.10 ~ 3.12（没有也没关系，引导文档从零教起）
- 磁盘 2GB、首次配置需联网（装依赖 + 下载 ffmpeg 约 80MB + Edge 配音联网）

## 快速开始

```
你：帮我用 D:\素材 里的视频出一批保温杯的短视频带货视频
Claude：检查环境 → 选配音 → 导素材打标签 → 给你文案确认 → 出片 → 报成片路径
```

## 法律与合规（重要）

- 本 skill 只用**你自己拍摄或已获授权**的视频素材和音乐，不内置任何第三方版权内容
- 文案层内置《广告法》禁用语本地检查（绝对化用语、功效承诺等），出片自动过检
- 医药功效、金融投资回报、烟草等违法广告品类一律不接
- **投放内容的法律责任由使用者承担**，发布前请自行复核
