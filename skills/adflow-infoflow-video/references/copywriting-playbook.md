# 口播文案方法论（写文案前必读）

第 3 步写文案时按这份手册走：先选型 → 配钩子 → 排节奏 → 画情绪 → 自检 ≥3 项 → 再给用户看。

## 一、先选脚本类型（六选一）

```
这条文案核心诉求是什么？
├── 解决明确痛点 / 功能性产品 → 痛点解决型
├── 日常高频、生活化品类     → 场景植入型
├── 效果可量化、可对比       → 开箱测评型
├── 要教育市场 / 输出干货    → 口播种草型 或 教程演示型
└── 靠情感/关系共鸣带出产品  → 剧情种草型
```

| 类型 | 句序骨架（22~30 秒 / 8~12 句照此排） | 适用 |
|------|------|------|
| 痛点解决型 | 钩子戳痛点 → 痛点放大(给证据) → 产品出场 → 效果画面 → 卖点2 → 信任 → CTA | 功能性产品、痛点明确 |
| 场景植入型 | 生活场景还原 → 场景2 → 产品自然融入 → 顺手用 → CTA | 日用、食品、家居 |
| 剧情种草型 | 剧情设定 → 冲突升级 → 反转高潮 → 产品破局 → CTA | 情感共鸣、送礼、家庭关系 |
| 口播种草型 | 身份锚定(我是谁) → 干货1 → 干货2 → 私藏推荐 → 信任背书 → CTA | 需要背书、教育市场 |
| 开箱测评型 | 开箱钩子 → 外观 → 功能实测 → 效果对比 → 提一个缺点 → CTA | 新品、效果可量化 |
| 教程演示型 | 成品/结果前置 → 原料工具 → 步骤1/2/3 → 成品展示 → CTA | 教程、制作、搭配 |

要点：
- 骨架是句序参考不是填空题，爆款参考怎么排就跟爆款排
- 测评型敢提一个小缺点，可信度反而涨
- 教程型步骤多可以加到 12 句，其他类型别超过 10 句

## 二、钩子：第一句十种手法（3 秒内必须命中一种）

| 手法 | 例句（照这个长度感觉写） |
|------|------|
| 痛点提问 | 还在为掉发烦恼吗 |
| 利益前置 | 三块钱解决了大问题 |
| 冲突对立 | 婆婆非说这钱白花了 |
| 悬念 | 最后一个真的绝了 |
| 反差 | 九块九用出了九百的效果 |
| 共鸣 | 熬夜带娃的都懂 |
| 数据冲击 | 十个人有九个买错了 |
| 反常识 | 越贵的反而越伤脸 |
| 场景代入 | 早上赶地铁的姐妹听我说 |
| 身份锚定 | 干了八年烘焙，说句实话 |

反面清单（写了就重写）：「你是不是也…」「今天给大家推荐」「XX真的这么难吗」「家人们谁懂啊」。

## 三、节奏与信息切换

- **一句 = 一个镜头 = 2~3 秒**：22~30 秒对应 8~12 句，全文 120~150 字
- 一句只说一件事；相邻两句信息必须换（新画面 / 新卖点 / 新情绪），同一信息最多连两句
- 节奏公式四选一，写完通读一遍检查是不是这个感觉：
  - 快切：句句短促，信息密集（测评、种草）
  - 叙事：单线推进，越说越近产品（剧情、口播）
  - 循环：重复句式强化记忆（对比、盘点）
  - 递进：一层比一层狠地放大痛点或利益（痛点解决型）

## 四、情绪曲线（写前先定一条，写完对着查）

- 痛点型：担忧 → 共鸣 → 看到解法 → 安心下单
- 种草型：好奇 → 认同 → 渴望 → 想下单
- 剧情型：代入 → 冲突 → 反转 → 释然
- 教程型：好奇 → 跟着做 → 成就感 → 想分享

从头到尾一个调 = 平淡，重写。

## 五、爆款潜质自检清单（≥3 项才交给用户）

写完逐条打勾，命中不到 3 条回去改，改法：换钩子手法 / 换人群视角 / 加一个信息增量点。

- [ ] 受众痛点真实：这批人真的天天被这事困扰
- [ ] 钩子有张力：第一句命中上表一种手法，不是平淡陈述
- [ ] 有信息增量：观众能带走一个不知道的点（数字/方法/对比/反常识）
- [ ] 情绪有起伏：按第四节的曲线走，至少一次明显转折
- [ ] 解法闭环：痛点 → 产品 → 效果 → 行动，链路不断
- [ ] 节奏不拖：8~12 句撑满 22~30 秒，没有凑数句

## 六、口语化铁律

- **口播短句，一句 ≤15 字为目标，一句说清一件事；意思必须完整，绝不为了凑短把话拦腰截断**
- 逗号句号按呼吸断：念到哪喘气就断到哪
- 不用书面连接词：此外 / 因此 / 然而 / 综上所述 / 不仅…而且
- 不端广告腔：「赶紧下单」「手慢无」少用，用「我自己回购了三次」「能囤就囤点」这种劝朋友的口气
- 感受必须翻译成画面和动作：不写「很好吃」，写「咬下去咔嚓一声」；不写「效果很好」，写「第二天照镜子，嘴角压不住」
- 专业名词翻译成人话：「5 微米颗粒技术」→「上脸细腻到看不见粉感」

## 七、合规（详细清单见 [compliance.md](compliance.md)，这里只记写作时的活原则)

- 极限词不是删掉完事，改成可证实的口语：「最干净」→「洗得挺干净」；「100% 有效」→「我自己用下来挺管用」
- 功效说主观体验：「用一段时间感觉…」，不打包票
- **价格必须带规格单位**：「29 块 9 三袋」，不裸报价格
