# 爆款拆解模板（用户给了参考爆款时用）

用户给了爆款视频/爆款文案让「照这个感觉出片」时，先按本模板拆解，再进第 3 步写文案。拆的是结构和节奏，**画面和原声一律不搬**（版权红线）。

## 拆解输出（拆完给用户过目一眼，确认拆对了再仿写）

### 1. 结构拆解表

| 句/镜 | 秒数 | 段落功能 | 钩子/CTA 手法 | 台词原句（或画面描述） |
|------|------|------|------|------|
| 1 | 0-3 | 钩子 | （命中哪种手法） | … |
| 2 | 3-6 | 痛点放大 | — | … |
| … | … | … | — | … |
| 末 | … | CTA | （引导方式） | … |

- 是视频就抽帧看画面（`import_materials.py` 同款抽帧思路，或让用户给截图）；是文案就直接逐句拆
- 段落功能按 [copywriting-playbook.md](copywriting-playbook.md) 第一节的六型骨架对号

### 2. 六维评分（每维 /10，给一句理由）

| 维度 | 评分 | 理由 |
|------|------|------|
| 钩子强度 | | 3 秒内命中手法没有，张力够不够 |
| 信息密度 | | 有没有增量点，废话多不多 |
| 节奏控制 | | 句子长短变化、信息切换快慢 |
| 产品展示 | | 产品出场时机和方式自然不自然 |
| 情绪曲线 | | 情绪有没有起伏转折 |
| 转化引导 | | CTA 自然不自然，力度够不够 |

### 3. 可复用因子（拆解的真正产出，仿写就仿这些）

- 结构：<哪型骨架，句序怎么排>
- 钩子：<用的哪种手法，张力来自哪>
- 节奏：<节奏公式、句长分布>
- 情绪：<走的哪条曲线>
- 表达：<值得学的口语句式，抄 2~3 个句式不算抄内容>

## 仿写规则

- 学「怎么说的」，不抄「说了什么」：结构、节奏、情绪曲线照搬，词句全部重写
- 可复用因子带进第 3 步：按 playbook 选型对号入座，自检清单照跑
- 拆解结论一句话给用户：「它爆是因为 ___，我们照搬的是 ___」
