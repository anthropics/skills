# 卡点/快闪节奏出片 Skill（beat-cut-video）

给 Claude Code 用的自然流量卡点短视频生产 skill：**你给 BGM 和视频素材，Claude 把关版权、帮选风格，本地引擎用 librosa 提取真实鼓点，剪出切点全部踩拍的热门卡点/快闪成片。全程无配音无口播。**

## 它能干什么

- 一首 BGM + 一批视频素材 → 自动出卡点/快闪竖屏成片（切点全部落在真实鼓点上，快的时候 0.5 秒一刀）
- 三种风格：`flash` 快闪（每拍一刀+白闪+punch 缩放+隔刀镜像）/ `standard` 标准卡点（平稳两拍高潮每拍）/ `build` 前缓后炸（自动找 drop）
- 大字快闪：给几个词（如"夏天 旅行 自由"），文字踩着鼓点弹出
- 段落感知：按小节能量自动分平稳/高潮段，高潮加密切点，不是死板等间隔
- 自动选精彩镜头：按画面运动强度打分，重音刀配动得最狠的画面、平稳刀配安静段（素材随手拍也能挑出有戏的段落）
- 倒放混切 + 冲击抖动：部分镜头倒放"回手"，重音刀每隔几个把 punch 缩放换成画面抖动，花样不重样

## 三大特点

1. **BGM 是主时钟**：和"文案出片"（配音当主时钟、2-3 秒一镜）相反，这里鼓点在哪刀落在哪——librosa 提取节拍与起音强度，变奏跟得住，弱拍不丢（安静前奏也全程跟拍），切点锁在 30fps 帧网格上刀口不虚。
2. **不依赖任何大模型 API**：引擎层纯本地确定性执行（librosa 节拍分析 + moviepy/ffmpeg 渲染），没有 API key 也能全流程跑通；想精挑画面顺序可以让 Claude 看图打标签（可选，不打标直接出片）。
3. **纯小白友好**：一句话让 Claude 干，脚本输出全是大白话；从装 Python 开始的手把手引导文档齐备。

## 系统要求

- Windows 10/11 64 位（Mac/Linux 理论可跑但未适配）
- Python 3.10 ~ 3.12（没有也没关系，引导文档从零教起）
- 磁盘 2GB、首次配置需联网（装依赖 + 下载 ffmpeg 约 80MB）

## 快速开始

```
你：用 D:\素材 里的视频 + D:\音乐\这首歌.mp3 做个卡点快闪，词就写 夏天 旅行 自由
Claude：检查环境 → 版权问话 → 导素材打标签 → 建议 flash 风格 → 出片 → 报成片路径+BPM+切点数
```

## 法律与合规（重要）

- **BGM 是主角，版权第一红线**：只用你自己创作或已获授权的音乐；skill 不内置也不提供任何第三方音乐
- 只用**你自己拍摄或已获授权**的视频素材；不扒别人的视频当素材
