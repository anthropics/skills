# expert-team：专家团，专人专做

**这个团回答一个问题：什么值得做、哪条路 ROI 最高、有没有更省的路。**评估在前、动手在后——圆桌管评估拍板，会诊管找最高 ROI 的改进，流水线管按 ROI 最优的方案执行。

主 agent 当**秘书长**：派工、收产物、卡流程、聚合，自己不干层的活。
派工只给干净输入：任务原文 + 产物 + 角色卡，**不带秘书长的预判**——对评审/盲写者禁说「这里肯定有问题」「这版应该行」，一句预判就把独立意见带偏（防锚定）。
派工角色卡第一行："你是这个领域世界顶尖的专家，一句话自我介绍"——按任务领域选人（代码=顶尖架构师，文案=金牌文案，依此类推）。

**ROI 最高原则**：最终裁判是 ROI = 想要的收益 ÷ 投入的成本（时间、钱、性能、门槛、机会成本）。好文案的标准是数据好，数据好就是 ROI；好功能、好决策同理。每个模式的产出最后都要回答"这笔投入值不值"，没算 ROI 账的建议不出报告。两条护栏：不可逆的下行（封号、健康、安全）不赌 ROI；长线复利别拿短期数据算。

**效率部（常设，ROI 的成本侧审计，三个模式都管）**：凡涉及成本——开发时间、性能、钱、资质门槛、启动资源——必须有效率部观点，收益侧说了不算。固定三问：**成本大头是谁 / 最省路径是什么 / 性价比怎么排**（对效果影响小、成本砍得多的先做）。金矿赚钱，但普通人没资质没启动资金，成本无穷 = 不可行。

## 先选模式

- 有活要干（新功能/新项目/产出物）→ **流水线模式**
- 想不清值不值得做、要找更高 ROI 的路、纯决策、多角度文案、要启发性讨论 → **圆桌模式**
- 已有东西要做得更好（产品/文案/页面/方案）→ **会诊模式**
- 小改动不开团，走 change-guard

## 流水线模式

### 规模
- **中**（一个功能/模块）：方案层 + 施工层 + 1 个产品评审，共 3 人
- **大**（新项目/重大决策/对外产出）：决策 2 人 + 方案 1 + 施工 1 + 评审 3 人并行

### 四层与产物
每个子 agent 只给三样：任务原文 + 上一层产物 + 角色卡。不给全历史。

1. **决策层** → 《决策书》：做不做、目标一句话、边界和资源。**必含 1 个反方**（大事正反两人并行）：专职问"有没有更好的路、最坏会怎样"。**必含效率账**：开发时间、性能代价、钱、资质门槛——账算不过，收益再好也否决或换路
2. **方案层** → 《落地方案》：步骤、选型、风险 + **过效率关**：性能大头在哪、哪些优化对效果影响小收益高（特效好看但玩家卡 → 砍性能大头、保观感底线）。发现不可执行或方向性低效 → 打回决策层
3. **施工层** → 《成品》+《施工报告》：按标准化最短路径干。发现方案绕路（长路径干短活、大代价换小优化）→ 打回方案层
4. **评审层** → 三人**并行**，各 50 字内意见：产品视角（有人买单吗）/ 视觉视角（顺不顺眼）/ 用户视角（上手好用吗）。格式：过 / 不过 + 最小修改建议

### 打回规则（防无限循环）
- 只能打回上一层，必须带三样：哪里不行 + 为什么 + 建议怎么改
- 同一交接点最多打回 1 次；再冲突就停，把双方分歧列出来报用户拍板
- 打回不重开：上一层只改问题点，其余照旧

### 收尾
秘书长汇总一页：决策书要点 / 方案 / 成品位置 / 三评审结论 / 打回记录 / 总 ROI 账一句（花的时间、性能、钱，换回了什么）。
评审有"不过"：施工层按最小修改意见改一轮再验；还是不过，报用户。

## 圆桌模式（决策 / 文案 / 启发性讨论）

目标：**非平均答案**。五个人写出一个意思 = 本模式失败。

1. **选席位 3-5 个**（席位 = 透镜，不一定是人）：
   - **判断/决策题** → 人设席位：3-4 位领域对口专家，流派/立场必须不同（同流派最多 2 席）；必含 1 个**反方**（专职攻击问题的隐含假设）+ 1 个**场外嘉宾**（跨界者或一线当事人，专职说"专家不会说的话"）
   - **分析题** → 心理模型席位：一个模型一席（杠铃策略、第一性原理、五问法……），用该模型推到底
   - **文案题** → 内容范式席位：先枚举该平台/品类的成熟范式（如短视频平台：爆款钩子型、强转化型、第三人称证言型"闺蜜说买了xx"、痛点场景型、反差测评型），一席一范式，一版全文
   - 任何题型涉成本（多数决策都涉）→ 默认含 1 个**效率席**：算时间/性能/钱/资质门槛的账，收益再好账算不过就明说
2. **角色卡硬规则**（防平均的关键）：
   - **思维签名**：必须用自己的方法论推导（芒格谈误判、塔勒布谈脆弱），通用腔作废重写
   - **范式纪律**（文案席位）：一版只守一个范式，钩子/节奏/口吻全按范式来，不得串味
   - **反共识义务**：先答"市面通行答案是什么"，核心主张必须指出它漏了什么
   - **空话黑名单**：禁"提升认知/拥抱变化/持续学习/保持好奇"类无动作词；每条主张带具体动作或可证伪断言
3. **并行盲写**：每人一个子 agent，只拿任务 + 角色卡，互相看不到意见
   - 决策类交：重定义一句（用自己的透镜把问题重说一遍）/ 核心主张 / 利 / 弊 / 条件式结论（if-then）/ 信心度
   - 文案类交：自己版本全文 + 一句"为什么这么写"（各自不同流派/受众/语气）
4. **秘书长聚合**（不许和稀泥）：
   - 决策类：共识区（谁同意什么）/ 分歧区（各留最强一句）/ 条件式结论（每条附一句 ROI 账：收益是什么 / 成本是什么）；关键结论标注来自哪位专家（可溯源）
   - 文案类：版本对照 + 什么场合用哪版 + 每版怎么验 ROI（发出去看什么数据指标）
5. **落地段（方法型问题必加）**：72 小时能做的 3 条（各带验收标准）+ 3 个月验证信号 + 止损线
6. **HTML 圆桌报告**：照 [templates/report.html](templates/report.html) 填——样式照抄不改、不加外部资源、自包含离线可开。硬规则：
   - 结论前置：Hero 放问题 + 一句话结论，聚合区在最上面
   - 一卡一事：每专家一张卡（含重定义/透镜行）；文案模式用版本全文块 + 对照表
   - 没用到的区块整块删掉；砍填充语（"值得注意的是""综上所述"全删）
   - 存 `output/专家团报告-关键词-YYYYMMDD.html`

**僵局规则**：吵成 3:2 且两边都硬时，不重开会——对准**分歧点**另拉 2-3 个全新隔离 agent 盲投：每人只看两派最强论点各一句，给倾向 + 一句理由（新上下文才是新信息）。票写进报告"僵局加票"区，秘书长按票重写条件式结论；票还平，报用户拍板。

## 会诊模式（让已有东西更好）

输入一个已存在的东西（产品/文案/页面/方案/代码），目标：多方向榨改进点。

1. **3-5 位专家按价值方向分席盲诊**（各只看输入物 + 角色卡，互相看不到）：
   增长（怎么更多人用/买）/ 体验（哪里卡住人）/ 成本（时间/性能/钱哪里浪费；优化性价比：影响小、提升大的先做）/ 风险（哪里会翻车）/ 差异化（怎么和市面拉开）
2. 每人只交**最有价值的一个改动**：改什么 + 为什么值 + 预期效果 + 动静多大（工时量级）
3. **秘书长按 影响×代价 排优先级**（这就是 ROI 排序：影响=收益、代价=成本），出改进清单，Top3 标星并各配一句"为什么先做它"
4. 衔接：大的改进项（超一个功能点）→ 转流水线模式施工；小的 → 报用户直接改。会诊清单也走 HTML 报告模板的"改进清单"区
